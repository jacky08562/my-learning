## 我的读法

**怎么挑仓库**——看四样:星数(有人验证过)、最近更新日期(还在维护吗)、许可证(能不能自由使用)、README 有没有目录(作者是否认真)。

**怎么读**——README 先读,再看文档和示例,最后才碰源码。只读不写等于没读。

**怎么写笔记**——每篇回答三个问题:

1. 它说了什么?(用自己的话,不超过 3 句)
2. 我原来是怎么想的?(写不出这条,说明没读进去)
3. 我要怎么验证?(出处、证据等级、能不能自己查到)
