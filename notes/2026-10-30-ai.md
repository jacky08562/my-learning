# 2026-10-30 · 第一次用程序调用大模型

**目标**:搞明白"程序调用大模型"到底发生了什么,并且亲手跑通一次。
**结果**:跑通了,没装任何软件(只用 macOS 自带的 `curl` 和 `python3`)。

## 一句话结论

**大模型就是一个 HTTP 接口。** 你发一段 JSON 过去,它回一段 JSON 过来。所谓"AI 应用",99% 是在这段 JSON 前后做文章。

## 一次调用长什么样

请求(我发过去的):

```json
{
  "model": "openai",
  "messages": [
    { "role": "system", "content": "你是一个用中文回答的助手,回答不超过 50 字。" },
    { "role": "user",   "content": "用一句话解释什么是 token" }
  ]
}
```

响应(它回过来的,只留关键字段):

```json
{
  "choices": [{ "message": { "content": "token是模型处理的最小文本单元…" } }],
  "model": "gpt-oss-20b",
  "usage": { "prompt_tokens": 93, "completion_tokens": 341, "total_tokens": 434 }
}
```

三个必须记住的位置:

| 位置 | 作用 |
| --- | --- |
| `messages` | 对话历史。`system` 定规矩,`user` 提问题,`assistant` 是它之前的回答 |
| `choices[0].message.content` | 模型真正说的话 |
| `usage.total_tokens` | **计费依据**。API 按 token 收钱,不按次数 |

## 实测数据(比看文档有用)

| 现象 | 数据 | 说明 |
| --- | --- | --- |
| 一次简单问答的用量 | 输入 95 + 输出 194 = 289 tokens | 输入很小,输出才是大头 |
| 同一个问题再问一次 | 输入 95 + 输出 659 = 754 tokens | 同样的输入,输出量能差 3 倍 |
| 响应耗时 | 24 秒 | 免费接口慢;换成付费的国内接口通常是 1~3 秒 |
| 回答只有 26 个字却烧了 341 tokens | 因为**内部推理过程也计费** | 推理模型(thinking)的输出 token 远高于你看到的答案 |

## 踩到的坑:HTTP 状态码

调用失败时,先看状态码,不要瞎猜:

- `401` = 钥匙不对或没带钥匙
- `402` / `429` = 额度用完 / 被限流。实测时收到 `402 FREE_LIMIT`,要求 30 秒一次
- `000` = 根本没连上(网络问题,和代码无关)
- `500` = 服务端自己出问题,重试

## 代码

- [`ai/01-first-call.sh`](../ai/01-first-call.sh) — 一条 curl 命令,最快的验证方式
- [`ai/02_chat.py`](../ai/02_chat.py) — 只用标准库的 Python 版,能放进程序里

两者请求的是同一个格式。**换模型只需要改三个环境变量**,代码一行不用动:

```bash
API_URL=https://api.deepseek.com/chat/completions \
MODEL=deepseek-chat \
LLM_API_KEY=sk-你的钥匙 \
./ai/01-first-call.sh "你好"
```

## 为什么这件事重要

学会了这个格式,你就同时学会了:怎么接国产大模型、怎么接 OpenAI、怎么用 Ollama 跑本地模型、怎么看懂任何一个"AI 工具"的源码。它们全是这一套。
